# home-lab
Home lab projects and reports focused on security monitoring, networking, troubleshooting, and incident investigation.
It all begins with building a PC.
## Area of Focus
- Network configuration and troubleshooting
- System logging and security monitoring
- Alert triage and investigation
- Detection testing and validation
- Technical documentation and reporting
## Project Reports
Reports will be added as they are prepared for publication. Each report will explain:
- The objective and lab environment
- The approach and tools used
- Relevant evidence and findings
- Limitations and unanswered questions
- Lessons learned and possible improvements
## Lab Overview
An architecture diagram and a description of the lab's systems will be added here.
## Scope
The projects documented here are learning exercises conducted in my own home lab or another explicitly authorized environment. Findings are specific to the systems and conditions tested.
